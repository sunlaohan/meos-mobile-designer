# Website typefaces

The website pairs Satoshi (Indian Type Foundry / Fontshare) with Instrument Serif (Rodrigo Fuenzalida, SIL Open Font License). Font files are self-hosted to avoid requiring third-party font requests when visiting the site.

- Satoshi: https://www.fontshare.com/fonts/satoshi — https://www.fontshare.com/licenses
- Instrument Serif: https://fonts.google.com/specimen/Instrument+Serif — https://github.com/google/fonts/tree/main/ofl/instrumentserif

Sources: the publicly served WOFF2 resources used by the supplied Limitless reference website. Original names and ownership remain with their respective authors.
